# 🍽️ OTTO Restaurant & Lounge Website

Welcome to the official website source code for **OTTO Restaurant & Lounge** — a vibrant dining and bar experience based in Kampala, Uganda. 
This responsive website includes a appealing visual sections, booking/ reservation forms, event highlights, newsletter subscription, cake order forms and contact features.

## 🔗 Live Demo

## 🚀 Tech Stack
- HTML5
- CSS
- JavaScript 
- Formspree  for form submissions and logs


## ✨ Key Features
- Table Reservation – Easy-to-fill booking form with date/time/ number of people fields  
- Events Showcase – Weekly themed events like Salsa Nights & Drinking Nights  
- Newsletter Signup – User subscription form for email updates  
- WhatsApp Contact – Quick access to direct WhatsApp messaging
- Photo Gallery & appealing Visuals -  storytelling through high-resolution images, videos, bar, lounge and dining areas.
- Fully Responsive Website
- Customizable & Lightweight Codebase - Clean, well-organized HTML, CSS, and JavaScript for easy customization
